# Frontend Design — 微信小程序 UI 设计规范

从"能用"到"好看"的设计方法论，专为为家航的用户群优化。

## 用户画像

为家航核心用户：**建材市场消费者**
- 年龄：25-65 岁（重点是 40+ 中老年）
- 场景：在大型市场内找店铺、比价格
- 痛点：方向感差、店铺难找、看不懂小字

## 设计原则

### 1. 大字大按钮
- 最小可触摸区域：48×48px（微信规范）
- 正文字号 ≥ 32rpx（小屏）~ 36rpx（大屏）
- 标题字号 ≥ 40rpx
- 按钮高度 ≥ 88rpx

### 2. 高对比度
- 主色调：橙色 #FF6B35（温暖、醒目）
- 辅助色：深蓝 #1A365D（信任感）
- 背景白 #FFFFFF，卡片浅灰 #F7F8FA
- 文字黑 #1A1A1A，次要文字 #999999

### 3. 室内导航特殊设计
- 地图页面全屏，无干扰元素
- 当前位置：蓝色脉冲圆点
- 目标店铺：红色大头针 + 店名气泡
- 路线：粗实线（≥ 6rpx），高亮色
- 楼层切换：底部大标签（当前楼层高亮）
- 方向指示：大箭头 + 距离文字

### 4. 简约操作流
- 首页核心功能 ≤ 3 个：搜店铺 / 看地图 / 找领航
- 搜索栏置顶，支持语音输入
- 减少弹窗，多用底部 sheet
- 操作反馈：震动 + 颜色变化

## 微信小程序适配

### WXML 结构规范
```
每个页面 ≤ 3 层嵌套
列表用 wx:for，不用嵌套 scroll-view
关键元素加 id 用于自动化测试
```

### WXSS 样式规范
```
用 rpx 单位，基于 iPhone 6 (375px)
flex 布局为主，grid 为辅
避免 fixed 定位（Android 兼容问题）
```

### 组件库选择
- 优先用 WeUI（微信官方）
- 复杂交互用 TDesign 小程序版
- 地图用腾讯地图小程序 SDK

## 设计检查清单

- [ ] 单手操作可达（拇指热区）
- [ ] 文字可读（对比度 ≥ 4.5:1）
- [ ] 按钮够大（≥ 88rpx）
- [ ] 加载态有骨架屏
- [ ] 空状态有引导文案
- [ ] 错误状态有重试按钮
- [ ] 支持 VoiceOver（无障碍）
