# Autoresearch — 自动化调研方法论

为家航项目的持续情报收集：竞品监控、价格追踪、行业动态。

## 调研触发条件

自动触发调研的场景：
- 用户提到"调研一下"、"查一下"、"有没有类似的"
- 进入新功能设计阶段（如"要做推荐引擎"）
- 每两周自动做一次竞品动态扫描

## 调研框架

### 1. 明确调研目标
```
- 一句话描述要搞清楚什么
- 为什么对项目重要
- 决策影响范围（影响哪个模块的设计）
```

### 2. 多源搜索
```
- WebSearch × 3 轮（不同关键词、不同角度）
- WebFetch × 5 篇关键文章（深入阅读）
- 交叉验证：至少 2 个独立来源确认同一事实
```

### 3. 结构化输出

调研完成后输出标准报告：
```
## 调研主题
## 核心发现（≤ 5 条）
## 竞品对比表
## 对为家航的启示
## 建议采纳的行动
## 信息来源列表
```

### 4. 存档
- 报告放在 `docs/research/` 下
- 命名格式：`YYYY-MM-DD_调研主题.md`
