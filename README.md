# 为家航

一个面向线下建材市场的 O2O 项目：室内导航 + AI 推荐 + 领航员带逛 + 在线下单。5 个子项目，约 54,000 行代码，独立完成。

## 背景

建材市场买东西效率很低：市场大、商户多、价格不透明，逛一天未必买齐。为家航想做"建材界的大众点评"：业主在手机上搜商品、看 AI 推荐、导航到店，线下还有"领航员"一对一带着逛、帮着砍价验货。

## 组成

| 子项目 | 类型 | 用户 | 技术栈 | 规模 |
|--------|------|------|--------|------|
| weijiahang-miniapp | 微信小程序 | 业主 | 原生 WXML/WXSS/JS | 30 页 |
| weijiahang-navigator | 微信小程序 | 领航员 | 原生 WXML/WXSS/JS | 20 页 |
| weijiahang-merchant | Web | 商户 | React 18 + Ant Design 5 | 13 页 |
| weijiahang-admin | Web | 平台运营 | React 18 + Ant Design 5 | 19 页 |
| weijiahang-server | 后端 | — | NestJS + PostgreSQL + Redis | 34 模块 · 39 实体 |

## 功能链路

- 业主：搜商品 → AI 推荐 → 商品详情 → 地图导航到店 → 下单 → 订单跟踪
- 领航员：接单大厅抢单 → 到市场等客户 → 带逛 → 拍照验货 → 佣金结算
- 商户：店铺、商品、订单、评价、营销、财务
- 运营：商家入驻审核、领航员认证审核、订单、结算、审计日志
- 后端：JWT 多角色认证、三级限流、审计日志拦截器、WebSocket 实时派单、BLE 信标室内导航、AI 推荐（Claude API）、动态定价

## 为什么停在这里

技术上基本完成了，但在商业模式复盘后没有继续投入：

1. 领航员靠佣金驱动，控制不住服务质量，大概率重演啄木鸟"维修刺客"的问题
2. 建材市场的利益链已经成熟——工人和商户之间有回扣体系，平台切不进去
3. 低频高价的生意，冷启动成本远大于创造的价值

教训是：写代码之前先想清楚谁为什么愿意用。技术能解决的问题，远少于商业上真正需要解决的问题。
